# Food Access Data Science

A workspace for a food access data science project. The repository currently contains project planning and data-handling guidance only. Analysis files, datasets, and findings have not been added.

## Project status

This is a project scaffold, not a completed analysis. The study area, research question, data sources, and analytical methods still need to be documented from the original project materials.

## Planned organization

- `docs/project-plan.md`: questions and evidence needed before analysis
- `notebooks/`: analysis notebooks, once available
- `src/`: reusable analysis code, if needed
- `reports/`: reviewed figures and findings, once available
- `data/`: local datasets, excluded from Git

Only the documentation exists at this stage. No installation or execution workflow is provided because no analysis code is included.

## Data handling

Keep raw data and personal or restricted information outside Git. Before adding a public dataset, record its publisher, source URL, access date, geographic coverage, units, and reuse terms. Publish aggregated or approved outputs only.

## Reproducibility

When the original analysis is available, document the environment, cleaning decisions, geographic joins, missing values, and steps needed to regenerate each result. Add conclusions only when supported by the included analysis.
